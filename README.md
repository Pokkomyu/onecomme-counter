# Poko-ChatCount

わんコメ(OneComme)用のカウンターテンプレートです。挨拶・新規フォロー・コメントを数えて、それぞれに倍率を掛けた合計を OBS に表示します。

- 合計 = Σ(カウント × 倍率)。例: 挨拶 1 回 = 10 歩
- 見出し・単位(歩 / 回 / 個 / pt など)・倍率・色は画面右の操作パネルで変えられます
- カウントと設定はブラウザに保存され、OBS を開き直しても残ります

## 入れ方

1. [Releases](../../releases) から `Poko-ChatCount-0.2.1.zip` をダウンロードします
2. わんコメ右上の「･･･」→「テンプレート」を開き、zip をテンプレート一覧にドラッグ&ドロップします
3. 追加された「Poko-ChatCount」を OBS にドラッグして、ブラウザソースを作ります
4. ブラウザソースの幅を `1920`、高さを `1080` にします
5. 左の表示エリア(幅 850px)だけが映るように、右側をクロップします

右側の操作パネルは、OBS のブラウザソースを「対話」で開いて操作します。操作パネルは配信に映さないでください。

## 以前の版から入れ替えるとき

0.2.0 までは「色々カウンター」という名前でした。0.2.1 から名前が変わり、わんコメの一覧には別のテンプレートとして追加されます。

1. 上の「入れ方」のとおりに「Poko-ChatCount」を入れ、OBS に新しいブラウザソースを作ります
2. OBS から「色々カウンター」のブラウザソースを消します。新旧を両方置いたままにすると、数が正しく数えられません
3. わんコメのテンプレート一覧に「色々カウンター」が残っていたら、消してかまいません
4. 0.2.0 を使っていた場合は、操作パネルの「配信が始まったら自動で 0 に戻す」にチェックが入ったままです。自分で 0 に戻したいときは、チェックを外してください

見出し・色・倍率などの設定とカウントは、そのまま引き継ぐ作りです。入れ替えたあと、いつもの見た目と数のままか一度見てください。配信中には入れ替えないでください。

## 数え方

| カウンター | 数えるもの |
| --- | --- |
| 挨拶 | 0 に戻してからはじめてコメントした人。判定方式を A〜C から選べます。チャンネルポイントの交換・連続視聴の通知もコメントとして挨拶の判定に入ります |
| 新規フォロー | わんコメに「〜さんにフォローされました」の通知が出たら +1。同じ人が外して入り直しても増えません |
| コメント | すべてのコメント。チャンネルポイントの交換・連続視聴の通知も 1 回と数えます。配信者本人のコメントは数えません |

挨拶の判定方式:

- A: 0 に戻してからはじめてコメントした人を全員数える
- B: わんコメが「初コメ(isFirstTime)」と判定した人だけ数える
- C: 0 に戻してからはじめてのコメントに挨拶ワードが入っている人だけ数える

0 に戻すのは、操作パネルの「全リセット」です。押すと「本当に 0 に戻しますか?」と出るので、「0 に戻す」を押します。カウントと、あいさつ済みの記録が一緒に戻ります。配信が終わっても、OBS を閉じても、押すまでは数が残ります。

配信のたびに自動で 0 に戻したいときは、操作パネルの「配信が始まったら自動で 0 に戻す」にチェックを入れます。0 時をまたいでも配信中は戻りません。

## 操作パネルの設定

- フォロー判定キーワード: 「,」で区切って複数書けます。既定は `フォロー,follow`(大文字小文字は区別しません)
- フォロワー総数(Twitch): わんコメから届いた数を操作パネルに表示します。見るだけで、配信には映りません

## 注意

- 「配信が始まったら自動で 0 に戻す」を入れているとき: Twitch だけの配信で、配信が切れて 1 分ほど後に再開すると、新しい配信として 0 に戻ります。
- 「配信が始まったら自動で 0 に戻す」を入れているとき: YouTube と Twitch の同時配信では、0 に戻るのは最初の 1 回だけです。
- OBS を先に起動しても、わんコメを起動すれば 10 秒ほどでつながります。
- 接続できないときは「デモモード」になり、テスト用のボタンでコメントを流せます。
- 数え漏れたときは、操作パネルの「手動補正」で直してください。
