# 色々カウンター(わんコメ用テンプレート)

わんコメ(OneComme)のカスタムテンプレートです。挨拶・新規フォロー・コメントを数えて、それぞれに倍率を掛けた合計を OBS に表示します。

- 合計 = Σ(カウント × 倍率)。例: 挨拶 1 回 = 10 歩
- 見出し・単位(歩 / 回 / 個 / pt など)・倍率・色は画面右の操作パネルで変えられます
- カウントと設定はブラウザに保存され、OBS を開き直しても残ります

## 入れ方

1. [Releases](../../releases) から `色々カウンター.zip` をダウンロードします
2. わんコメ右上の「･･･」→「テンプレート」を開き、zip をテンプレート一覧にドラッグ&ドロップします
3. 追加された「色々カウンター」を OBS にドラッグして、ブラウザソースを作ります
4. ブラウザソースの幅を `1920`、高さを `1080` にします
5. 左の表示エリア(幅 850px)だけが映るように、右側をクロップします

右側の操作パネルは、OBS のブラウザソースを「対話」で開いて操作します。操作パネルは配信に映さないでください。

## 数え方

| カウンター | 数えるもの |
| --- | --- |
| 挨拶 | その日はじめてコメントした人。判定方式を A〜C から選べます |
| 新規フォロー | 本文に「フォロー判定キーワード」を含むシステムコメント |
| コメント | すべてのコメント |

挨拶の判定方式:

- A: その日はじめてコメントした人を全員数える
- B: わんコメが「初コメ(isFirstTime)」と判定した人だけ数える
- C: その日はじめてのコメントに挨拶ワードが入っている人だけ数える

日付は 0 時で切り替わります。

## 注意

- **新規フォローの自動カウントは確認中です。** わんコメからフォロー通知がどの形で届くかは公式ドキュメントに書かれておらず、配信サイトによっては届きません。数え漏れたときは、操作パネルの「手動補正」か「フォロワー数の差分入力」で直してください。
- 「差分をフォロー数に反映」はフォロー数を上書きします。
- 接続できないときは「デモモード」になり、テスト用のボタンでコメントを流せます。
